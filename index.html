Dix niveaux, une seule chaîne

MONDE → FRANCE → → COMMUNE → LIEU → COFFRET → MOMENT → LUMIÈRE → MÉDIA → RÉCIT. Chaque niveau est une entité de plein droit : un fichier, un rôle, une cardinalité calculée sur les données. Cliquez pour descendre dans la chaîne.

Les lieux, entités uniques

Un lieu existe une seule fois, référencé par les coffrets : rien n’est dupliqué. Chacun porte une typologie, une matière, un statut de vérification et le nombre de coffrets qui l’utilisent. Cliquez pour filtrer la mosaïque sur ce lieu.

Les communes, à l’échelle de la collection

La densité réelle des coffrets, commune par commune. Cliquez pour filtrer la mosaïque. lieux sur apparaissent dans plusieurs coffrets : ils existent une seule fois dans les données et sont référencés, jamais dupliqués.

Ce que la collection sait vraiment

Chaque donnée de cette page vient d’un fichier de data/territories/lille-metropole/ : un coffret n’a pas de titre « décoratif », il a une commune, un lieu, un univers, des moments de mariage, une saison et une date. Les lieux sont des entités uniques référencées par les coffrets.

Un compteur affiché ici n’est jamais saisi à la main. Nous ne renseignons ni prix, ni horaires, ni disponibilité, ni prestataire : ces informations n’existent pas dans le jeu de données, et rien n’est inventé pour combler le vide. Quand une information manque, elle est annoncée comme manquante.

Lumière : lever, coucher, golden hour et heure bleue sont calculés (algorithme solaire NOAA simplifié, point de référence Lille 50,633 N / 3,067 E, précision ± 1 à 3 minutes) pour chaque date de coffret. Ce ne sont pas les coordonnées exactes de chaque lieu : à remplacer par des positions officielles.

Statuts de vérification

  • PROPOSÉ piste éditoriale — aucune valeur factuelle
  • TROUVÉ information générale, source officielle non rattachée
  • SOURCE OFFICIELLE appuyé par une source citée
  • À VÉRIFIER à confirmer avant publication
  • VÉRIFIÉ contrôlé en interne
  • CALCULÉ produit par un algorithme reproductible

Les 365 coffrets sont une collection éditoriale de démonstration : leur statut par défaut est PROPOSÉ. Les identités des lieux ne sont affirmées que lorsqu’une source est citée dans la fiche du coffret.
